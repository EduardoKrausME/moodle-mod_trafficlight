# Traffic Light (mod_trafficlight)

Traffic Light is a Moodle activity that lets students quickly tell their teacher how well they are following a lesson or a particular topic. Instead of waiting until the end of class, the teacher can see which students need an explanation or additional support.

## Student experience

Each student selects one of three states:

- **Green** — I understand and am doing well.
- **Yellow** — I have questions or need to review.
- **Red** — I need help or do not understand.

Students can update their status at any time. Each student has only one current response per activity: choosing a different colour replaces the previous status rather than creating a history of responses.

## Teacher dashboard

Teachers with permission to view the report see a dashboard showing the total number of students, response counts and percentages for each colour, and the students in each group. The dashboard also identifies enrolled students who have not responded.

This helps teachers decide whether to move on, revisit a topic, or offer extra assistance during class.

## Activity settings and permissions

When adding the activity to a course, the teacher provides a name and can add an optional prompt or description to explain what students should assess. Standard Moodle activity settings, including visibility and completion tracking, remain available.

The module defines separate capabilities for adding an activity, viewing it, submitting a status, and viewing the class dashboard. By default, students submit their own status while teachers view the dashboard.

Activity views are recorded in Moodle logs and can contribute to view-based completion tracking. The activity supports Moodle backup and restore and includes a privacy provider for student response data.
